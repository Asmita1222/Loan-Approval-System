# AI-Based Loan Approval Prediction System

A web application that uses Machine Learning to predict whether a loan application will be **Approved** or **Rejected**.
The user fills in a form, the browser sends the data to a Flask server, the server asks a trained Random Forest model for a prediction, and the result is shown on the page.

## Requirements

- **Python 3.9 or newer** (check with `python --version`; on some systems use `python3`)
- pip (comes with Python)
- A web browser (Chrome, Edge, Firefox ...)

No internet is needed to run the project once the libraries are installed.

## Installation and running (step by step)

### Step 1: Open the project folder in a terminal

Unzip `Loan_Approval_System.zip`, then open a terminal (Command Prompt, PowerShell, or Terminal) inside the `Loan_Approval_System` folder:

```
cd Loan_Approval_System
```

### Step 2 (recommended): Create a virtual environment

A virtual environment keeps this project's libraries separate from the rest of your computer.

**Windows**
```
python -m venv venv
venv\Scripts\activate
```

**macOS / Linux**
```
python3 -m venv venv
source venv/bin/activate
```

You should now see `(venv)` at the start of the terminal line.

### Step 3: Install the libraries

```
pip install -r requirements.txt
```

### Step 4: Train the model (recommended)

```
python train_model.py
```

This reads the dataset, cleans it, compares three algorithms, prints the accuracy, and saves the best model as `loan_model.pkl`.

> A trained `loan_model.pkl` is already included, so this step is optional. Still, running it is a good idea: a model saved with one version of scikit-learn can fail to load in another version. (If that happens, `app.py` automatically trains a new model when it starts, so the project will still run.)

### Step 5: Start the web application

```
python app.py
```

You will see a message like `Running on http://127.0.0.1:5000`.

### Step 6: Open the website

Open your browser and go to:

```
http://127.0.0.1:5000
```

Fill in the form (or click **Strong applicant** / **Risky applicant** to load an example) and click **Predict Loan Approval**.

To stop the server, press `Ctrl + C` in the terminal.

## How the project works

```
 Browser form  ──(JSON via fetch)──►  Flask /predict  ──►  ML pipeline  ──► prediction

       ▲                                                                       │

```

### The dataset

`loan_approval_dataset.csv` has 1000 loan applications with these columns:

| Column | Meaning |
|--------|---------|
| Gender, Married, Dependents, Education, Self_Employed | Applicant details |
| ApplicantIncome, CoapplicantIncome | Monthly income in rupees |
| LoanAmount | Loan amount in **thousands** of rupees |
| Loan_Amount_Term | Loan duration in months |
| Credit_History | 1 = good, 0 = not good |
| Property_Area | Urban, Semiurban or Rural |
| Loan_Status | **Target:** Y = approved, N = rejected |

**Important:** this dataset is *synthetic* (generated by `generate_dataset.py`). It has the same columns and the same kind of problems (missing values) as the popular public "Loan Prediction" dataset on Kaggle, but the applications are not real people. For the final submission you can replace it with the real Kaggle dataset (see below).

### Machine Learning steps (`train_model.py`)

1. **Load data** with Pandas.
2. **Handle missing values**
   - Text columns (Gender, Married ...) are filled with the most common value.
   - Number columns (LoanAmount ...) are filled with the median.
   - Credit_History is filled with the most common value.
3. **Convert categorical data to numbers** using One-Hot Encoding (for example `Gender` becomes `Gender_Male` and `Gender_Female`, each 0 or 1).
4. **Create two new features:** `Total_Income` (applicant + coapplicant) and `EMI_Ratio` (estimated monthly instalment divided by income).
5. **Scale** the numeric columns with StandardScaler.
6. **Split** the data: 80% training, 20% testing (stratified, so both parts have a similar Approved/Rejected ratio).
7. **Train and compare** Logistic Regression, Decision Tree and Random Forest using 5-fold cross-validation.
8. **Select the best model**, print its accuracy, confusion matrix and classification report.
9. **Save** the complete pipeline (cleaning + model) to `loan_model.pkl` with `joblib`.

Because the cleaning steps are saved inside the model, the web app can send raw form values straight to it.

**Result:** the Random Forest model reaches about **89.5% accuracy** on the 20% of data it never saw during training. (The exact number is printed when you run `train_model.py` and shown on the webpage.)

### The web app (`app.py`)

- `GET /` shows the page.
- `POST /predict` receives the form data as JSON, validates it, creates the extra features, calls `pipeline.predict()`, and returns the result (Approved/Rejected, approval chance, a short message and a few key points).

The "What stands out" points on the page are simple rules (credit history, EMI compared to income). They are hints for the reader, not the model's internal reasoning.

## Using the real Kaggle dataset (optional)

1. Download the "Loan Prediction" dataset's `train.csv` from Kaggle.
2. Rename it to `loan_approval_dataset.csv` and replace the file in this folder.
3. Run `python train_model.py` again.
4. Restart `python app.py`.

The column names are the same, so no code change is needed. Accuracy is typically around 78–82% on that dataset, which is normal for real, noisy data.

## Testing the project quickly

With the server running, you can also test the API from another terminal:

**macOS / Linux**
```
curl -X POST http://127.0.0.1:5000/predict -H "Content-Type: application/json" -d '{"Gender":"Male","Married":"Yes","Dependents":"1","Education":"Graduate","Self_Employed":"No","Property_Area":"Semiurban","ApplicantIncome":"6500","CoapplicantIncome":"2000","LoanAmount":"150","Loan_Amount_Term":"360","Credit_History":"1"}'
```

Expected: a JSON reply containing `"result": "Loan Approved"`.

## Troubleshooting

| Problem | Solution |
|---------|----------|
| `python` is not recognised | Try `python3`, or reinstall Python and tick "Add Python to PATH". |
| `No module named flask` (or sklearn, pandas) | Activate the virtual environment, then run `pip install -r requirements.txt`. |
| Warning about scikit-learn version when loading the model | Run `python train_model.py` again to create a model for your version. |
| `Address already in use` / port 5000 busy | Close the other program using port 5000, or change `port=5000` at the bottom of `app.py` (e.g. `5001`) and open that port in the browser. |
| Page shows old design after editing CSS | Hard refresh the browser with `Ctrl + F5`. |

## Limitations (good points to mention in your viva)

- The training data is synthetic; real banks use far more information and strict regulations.
- The model only learns patterns from past data, so it can repeat unfair bias present in that data. Real systems need fairness checks.
- This project is for learning and is **not** financial advice.
